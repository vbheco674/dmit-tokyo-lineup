### Premium Network

Premium 是更偏向中国大陆访问质量的东京线路。官方说明其使用 CN2 GIA（AS23764），参考平均延迟约 28ms、丢包低于 0.1%，并建议用于中国大陆面向型网站、在线游戏、直播、电商和其他低延迟业务。

Tier 1 的定位完全不同。DMIT 官方写得很直白：它主要服务亚太、北美和欧洲的国际流量，不针对中国大陆做专门优化。

所以，**“东京”不等于“CN2 GIA”**。这点非常关键。

你买了东京节点，只能确定服务器地点；真正决定中国访问体验的，是你选择了哪条网络产品线。

## 超出流量后会发生什么？

这是选择 DMIT Tokyo 时非常值得提前搞清楚的一项。

DMIT 官方文档目前定义了三种流量超额规则：

1. 超量后暂停；
2. 超量后限速；
3. 不限制。

实际采用哪种方式取决于具体产品。

对于用户来说，这个区别很实际。

假设你拿 VPS 跑网站，流量突然暴增：

* “暂停”意味着服务直接中断；
* “限速”意味着网站仍然在线，但吞吐能力下降；
* “不限制”则通常伴随更低的固定端口速度或不同的产品设计。

DMIT 也提供流量重置机制，绝大部分常规套餐可以付费重置；文档说明，重置费用通常按“续费价格 ÷ 计费周期”计算。

对于 Tier 1 页面上的 Max（IN/OUT）流量模型，这种设计尤其值得注意，因为它和传统双向累计流量不是一回事。

## DMIT Tokyo 和普通日本 VPS，真正该比较什么？

不要先比较“1GB RAM 谁更便宜”。

更有用的比较顺序应该是：

**第一，看用户在哪里。**

如果主要用户就在日本，那么东京节点本身已经解决了一个核心问题：物理距离。

如果主要用户在中国大陆，接下来就应该比较 Premium / Tier 1 的路线，而不是继续看 CPU。

如果主要用户在欧洲或者北美，那么东京本身未必是最合理的位置，哪怕它的国际互联质量不错。

**第二，看你到底需要多少流量。**

Premium TINY 只有 500GB，而 Tier 1 TINY 是 2TB Max（IN/OUT）；Tier 1 MEDIUM 更是达到 32TB Max（IN/OUT）。

如果你是下载、备份、镜像、跨区域传输之类的流量型业务，Tier 1 的产品结构会更容易理解。

**第三，看流量超额之后你能不能接受限速或暂停。**

这直接关系到业务连续性，不能等到流量跑完才发现套餐规则和预期不同。

**第四，最后才是 CPU 和内存。**

对于 Web、API、Docker、数据库之类的 workload，1GB 和 4GB 内存的差别当然很明显；但如果业务最敏感的是中国大陆访问速度，那么换成更大 RAM 却仍然使用不合适的线路，解决不了根本问题。
